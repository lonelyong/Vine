## 2. 框架 / 概念上的收益

### 2.1 删掉的是"缝两个可变世界"的机器

今天桥接的组成（`wc -l` 实测）：`ContentMirror` 326 + `DeltaChannel` 263 + `DrawListMemo` 226 +
`FrameWorker` 316 + `FrameRunner` 265 + `SceneRows` 121 + `EngineFrame` 72 + `DrawListBake` 930。

重设计后这些的职责被三样东西吸收：

| 今天的职责 | 重设计里的载体 |
|---|---|
| 镜像的副本与 delta 同步 | **不可变快照**（指针即版本） |
| memo 的键与失效 | 快照不可变 ⇒ 派生结果可按值缓存（键可比较） |
| 版本三元组（epoch / boxes / materials） | **快照指针**（一个指针说明一切） |
| 帧值双缓冲与半段交接 | `FrameValue` 值 + 一个引擎线程 |
| `refreshBoxes` / `refreshMaterials` | 发布时的**脏块集合** + `id→rev` 表 |

**判据**：`wc -l` 下降（`K5`）；`.ai/design/graphics-threading.md` 的 20 条约束里，约 10 条失去存在理由
（C8 / C12 / C14 / C16 / C18 / C19 被吸收，C20 升格为不可表达）。

### 2.2 概念数从 28 到 8

今天承担"跨世界"职责的具名类型（镜像/通道/备忘录/版本/帧值/半段/运行器/裁剪器…）在骨架里
只剩 8 个名词 + 3 个动词。**收益不是"更少类型"本身**，而是新问题的答案唯一：
"这条数据属于哪层？" 有唯一回答。

**判据**：SDK 里名字含 `Mirror|Delta|Memo|Version|Half|Runner|FrameMode|RunnerMode` 的公开类型数 → 0。

## 3. API 设计上的收益

| 今天的误用 | 今天怎么被发现 | 重设计后 |
|---|---|---|
| 帧在飞时 `addPass` / `removePass` | C20 运行时拒绝 + 一条诊断 | **不可表达**：计划是值，帧边界差分 |
| 用活相机做拾取/锚点 | N17 规则 + 一次记忆错误 | **不可表达**：查询吃 `FrameResult` 的 View |
| 用旧句柄/已释放对象 | 悬垂或 `kept` 兜底 | 答 `gone`（`T5`） |
| 在错误的线程编辑场景 | 靠约定 + TSan 事后 | 单写者（`C2`）+ TSan；交接需 happens-before |
| 手搓命令漏了材质值 | 今天回退到对象缓存（隐式） | 回退仍在，但**行来的命令**永不依赖活对象 |
| 四个模式枚举混用 | 靠文档 | 一个轴一个枚举 |

**量化**：会话形状入口 4 → 0；`RenderEngine.hpp` 里"必须按此顺序调用"类 `@warning` 的条数应显著下降
（今天该文件 1310 行，大量篇幅在描述时序）。

## 5. 资源回收上的收益（这一维最大）

| 项 | 今天 | 目标 |
|---|---|---|
| 规则 | "fence 一完成就清" + 时间窗 + parked + `kept` 兜底 | **有活快照引用即活，无则回收** |
| 判定 | `markUsed` / `release_token` / `release_requested` / `retirement` 协同（约 72–75 处） | 一次 `last_epoch < oldest_live` 比较 |
| 失败模式 | 悬垂（TSan 首轮 14 条警告全是寿命问题，0 条数据竞争） | 结构上无悬垂：句柄 + 代际 |
| 可测性 | 靠时序用例 + 兜底不断言 | 给定活快照集，回收集**可枚举**（`T6`） |
| 与深度 > 1 的关系 | 需要新增规则 | 每槽持有自己的快照引用 ⇒ 天然成立 |

**为什么这条最值钱**：TSan 首次运行的 14 条警告里，**没有一条是数据竞争**，全是寿命
（`removePass` 的 UAF、测试读了已释放的相机、两处 range-for 临时对象）。这类 bug 靠 review 抓不住，
靠规则也堵不住 —— 只有换结构（引用 + 代际）才消失。

## 9. 代价（诚实，逐条给"怎么知道我们付多了"）

| # | 代价 | 观察方式 |
|---|---|---|
| P1 | **结构共享写错会全垮**：深拷贝或 refcount 抖动会让发布比今天更差 | `N2`（发布 ≤ 250 µs）、`N3`（内存 ≤ 2×）、`N19`（元数据不整体拷贝）；`K1`/`K2`/`K11` |
| P2 | 内容侧从"几乎零分配"变成"块复制 + 句柄表" | 分配计数 + RSS |
| P3 | 声明式差分是新 bug 面（按名字匹配写错 ⇒ 每帧重建管线） | `builds` 稳态增量必须为 0（`T7`） |
| P4 | 注册表是全局状态（默认域）+ 少见的上锁 | 峰值对象数、锁持有时间（profile） |
| P5 | 迁移期两套并存 | 只存在于 `detail::` + 内部开关；**公开 API 不动**（`C11`） |
| P6 | 作者层收益有限（用户代码大体照旧） | 用"扩展成本"与"跨层代码量"衡量，而不是"API 变更数" |
| P7 | 这是一次重写而不是重构 | 五步各自可判死（§10），任一步不过就停在那一步 |

## 10. 迁移（五步，每步独立可判死）

| 步 | 范围 | 拿到的收益 | 判死条件 | 估算 |
|---|---|---|---|---|
| **0** | 修 `-audit` 的 X1–X10 / A1–A4 文档缺口 + `K7–K11` / `R31–R39` | 模型先自洽：引用带 revision、拾取带实例、共享原型有写者域 | 文档矛盾未清就不进代码 | 文档 |
| **1** | `Measure*` 加阈值 + 证据计数脚本 | 后面的优化可证；数字口径固定 | 阈值不稳就不进下一步 | 半天 |
| **2** | `detail::Snapshot`（hot/cold + `ContentRef{id,rev}`）+ 纯 `select`；**不带原型实例化** | 删镜像/delta/memo/版本的一半；旧帧读旧值 | `K1`/`K2`/`K3`/`K7` | 原型 + 对照表 |
| **3** | `ContentRegistry` + `{index,domain,generation}`；引擎表按 `(id,rev)`；删 parking | 寿命从猜变算；整类 UAF 消失 | `K6`/`K8` | 中 |
| **4** | `FramePlan` 声明式 + 帧边界差分 + `prepare` + 单 Session 多 Surface | 误用不可表达；预热可预算；多窗口不必多引擎 | `R21`/`R36`/`R37`/`K10` | 中 |
| **5** | 原型实例化（先 A 物化，再评估 B） | 子树复用；成本按 `T23` / `N3` / `K11` 实测 | 数字不成立就停在“原型 DAG 共享” | 独立实验 |

每步收尾（沿用仓库节奏）：全量构建 → `test_graphics` / `test_vsg` / `ctest` →
`scripts/tsan_check.sh`（0 警告）→ 八个文档门禁 → 提交。

## 11. 反方论点（详细回应）

| 反方 | 细节 | 回应 |
|---|---|---|
| "今天的约束多，但每条都被测试钉住" | C1–C20 背后有 548 + 537 条用例（提案时；当前 559 + 537） | `I1–I7` 是这些约束的**收敛形式**；迁移每步都跑全部既有用例（`K4`：**语义断言**改动 ≤ 5%，纯改名不计） |
| "C++ 里结构共享容易写错" | refcount 抖动、false sharing、`shared_ptr` 竞争 | 块不可变 + `shared_ptr<const 块>` 起步；发布只在一条线程；先测量再优化（`Q1`/`Q2`） |
| "指针身份省了一个注册表" | 地址即身份零成本 | 但代价是整类寿命机器（约 72–75 处，口径见 audit §2）与 UAF；注册表只在创建/销毁上锁，罕见 |
| "重写期维护双份" | 两套路径同时存在 | 原型只在 `detail::` 与内部开关；公开 API 不动；不合并就不发布 |
| "并行其实不是瓶颈" | 2000 drawable 相机移动约 2.1 ms，还没进 16 ms | **同意**。并行不是这版卖点；卖点是删机器（§2）与寿命规则（§5） |
| "快照内存会爆炸" | 每个快照一份块指针数组 + 共享块 | 块指针数组 O(行/32)；共享块不复制；`N3` 上限 2×，`K2` 判死 3× |
| "行预算/实例会让做法变复杂" | 实例数 × 原型行数 | 本来就是"共享的代价"，今天没有可见性才是问题；一条诊断即可（`R8`） |

## 12. 一句话总结收益

**不是"更抽象"，而是：能删掉一半机器（2519 行 → ≤ 600，同口径）、把 20 条时序约束收敛成 7 条结构不变量、
把"寿命"从猜变成算（约 72 处 → ≤ 20）、把三类误用（会话形状 / 陈旧句柄 / 活相机查询）从"靠规则"变成
"写不出来" —— 而代价是必须重新实现桥接与驻留层，所以按五步走，每一步用今天的测量、TSan 与 audit 的
`K7–K11` 当判据。**
