# Diagnostic codes: the stable identifier of a cause (see RenderDiagnostic::code).
#
# One line per code: `<code> — <what it means, and what a host does about it>`.
# The rule works BOTH ways (`scripts/check_diagnostic_formats.py`): a code a source file states must be here, and a
# code here must be stated by a source. A code is never reworded and never reused for another cause; when its last
# use goes, its line goes with it.
#
# The prefix names the module, because the vocabulary belongs to the module that reports (the SDK knows no `Vk*`):
#   vk.*      the direct-Vulkan backend (`src/plugins/gfx_backend_vk`)
#   engine.*  the render engine itself (`src/viz/graphics`)
#   appfw.*   the host framework above the engine (`src/fw/appfw`): a finding the layer above injects
#             through RenderEngine::reportEngineProblem, which the engine counts under origin Host

# --- vk backend: the memory pool (see vk-backend.md 2.12) ---
vk.memory.out_of_memory       — the device heap is exhausted; releasing content may help
vk.memory.driver_refused      — vkAllocateMemory refused for a reason that is neither a lost device nor an exhausted heap
vk.memory.no_type             — no memory type this resource allows serves the usage: this device cannot host it
vk.memory.invalid_request     — a resource asked for zero bytes: a content defect
vk.memory.not_open            — device memory was asked for before the pool was opened: a wiring defect
vk.memory.internal            — the pool contradicted its own invariant: a defect in the allocator

# --- vk backend: bringing the device up ---
vk.init.loader_missing           — no Vulkan loader could be opened; install a driver (or point VK_ICD_FILENAMES at one)
vk.init.instance_failed          — vkCreateInstance refused: the loader is there and this machine cannot be a Vulkan client
vk.init.no_device                — the machine lists no usable physical device (none at all, or the loader could not list them)
vk.init.no_queue                 — a physical device exists but none serves a graphics queue (plus present, when a window was asked for)
vk.init.device_failed            — vkCreateDevice refused: the driver would not serve this feature/extension set
vk.init.api_version_low          — the device reports a Vulkan version below 1.3: this backend records synchronisation 2 and dynamic rendering, both core there
vk.init.device_features_missing  — the 1.3 device does not offer the `synchronization2` / `dynamicRendering` FEATURES the backend enables (a version is not a feature)
vk.init.dynamic_state_missing    — the device lacks VK_EXT_extended_dynamic_state3 (polygon mode, colour blend): this backend moves cull / depth / polygon / blend off the pipeline, so it cannot serve one
vk.init.command_machinery_failed — the command pool, the frame's command buffer or the fence could not be created: the session cannot drive frames
vk.init.memory_pool_failed       — the device memory pool could not be opened (see the memory report beside it)
vk.init.content_pool_failed      — the content layouts / descriptor pool could not be created: this device cannot draw

# --- vk backend: the frame and the warm-up (see vk-backend.md F4/F5) ---
vk.session.not_initialized       — a frame was handed to a device that is not up: initialize it (or rebuild the lost session)
vk.frame.begin_failed            — vkBeginCommandBuffer refused: the frame was skipped
vk.frame.end_failed              — vkEndCommandBuffer refused: nothing that was recorded ran
vk.frame.did_not_complete        — the submitted frame's fence did not signal and the device is not lost: the picture is incomplete
vk.prepare.batch_failed          — the warm-up's transfer batch could not be opened: the next frame uploads that content again
vk.prepare.batch_not_closed      — the warm-up's batch could not be closed: the copies it recorded never ran and cannot be retried
vk.prepare.batch_not_run         — the warm-up's batch was submitted and the queue refused it: the images were never written
vk.driver.message                — a Vulkan layer or driver logged a message: its text is the driver's own, not ours

# --- vk backend: what a draw could not be drawn with (see vk-backend.md F2) ---
vk.content.no_program               — the draw named no program and the device has no default one: it drew nothing
vk.content.no_geometry              — the draw carried no geometry description: it drew nothing
vk.content.primitive_absent         — the draw names a primitive its geometry does not have: it drew nothing
vk.content.program_refused          — the program could not be staged (compile or shader module); the loader's report says which stage
vk.content.program_stage_missing    — the program declares no module for a stage a graphics pipeline states (this backend's is a vertex AND a fragment stage): the draw was skipped
vk.content.geometry_refused         — the geometry's streams could not be formatted or uploaded: the draw was skipped
vk.content.instance_stream_refused  — the draw's instance transforms could not become a vertex stream: the draw was skipped
vk.content.pipeline_refused         — vkCreateGraphicsPipelines refused the state the draw resolves to: the draw was skipped
vk.content.screen_no_program        — a full-screen draw named no fragment program: it drew nothing
vk.content.screen_program_refused   — a full-screen draw's fragment or vertex stage could not be staged: it drew nothing
vk.content.screen_pipeline_refused  — the full-screen pipeline was refused: the draw was skipped
vk.content.screen_no_source         — a full-screen draw named no source target, so there is nothing to sample
vk.content.wrong_path               — a full-screen draw reached the content path (or a scene draw the screen path): a wiring defect
vk.content.stand_in_missing         — the 1x1 stand-in every absent texture slot binds could not be made: draws were skipped
vk.content.uniform_ring_full        — the frame's uniform ring had no slice left: the draw was skipped and the ring grows
vk.content.descriptor_set_missing   — the descriptor cache could not hand out a set: the draw was skipped
vk.content.material_texture_skipped — a material's texture could not be made resident: the slot was left absent
vk.content.nothing_to_draw          — the draw named neither an index stream nor vertices: it drew nothing
vk.content.plan_missing           — the frame head did not resolve every command of a draw packet: the recorder refused rather than guessing
vk.content.no_runnable_pass         — the frame had no pass this backend can run: nothing was submitted

# --- vk backend: the device gate (see vk-backend.md 2.11) ---
vk.device.reentry                   — a host verb was called from inside a frame body: it did nothing (it would wait for itself)

# --- engine: what a frame's compile found (see graphics-frame-pipeline.md) ---
engine.compile.cycle                    — passes depend on each other in a cycle; those passes are skipped
engine.compile.unpublished_scene        — a pass draws a scene that was never published
engine.compile.picture_shape_mismatch   — the rectangle a pass draws into and its camera's shape disagree
engine.compile.input_not_produced       — a declared input nothing published this frame
engine.compile.output_to_window         — a pass publishes an output name but renders into the window
engine.compile.duplicate_output         — two passes publish one output name this frame
engine.compile.layered_depth_refused    — a layered depth view is not built yet, so the declaration is refused
engine.compile.depth_view_conflict      — two passes name different depth views for one target
engine.compile.plan_refused             — the plan statement was refused (see PlanResult)

# --- engine: a pass declaration the engine could not honour ---
engine.pass.layer_mask_empty          — a content pass' layer mask selects nothing, so it draws an empty picture
engine.pass.target_invalid            — a pass' Target value states two forms at once (or a form without its payload)
engine.pass.output_invalid            — a pass' Output value promises both a whole target and one image
engine.pass.output_target_mismatch    — a pass promises a whole target it does not render into
engine.pass.output_image_mismatch     — a pass promises one image of a target it does not render into
engine.pass.output_collision          — two passes claim one image as their output
engine.pass.input_not_produced        — a pass' declared input was produced by nothing this frame: it draws nothing
engine.pass.input_target_not_produced — a pass reads a whole target no pass writes, so nothing fills it
engine.pass.input_image_not_produced  — a pass reads an image (or a depth) no pass declares, so nothing fills it
engine.pass.image_unbound             — a declared image is bound to no target, so it cannot be resolved either way
engine.pass.changed_during_frame      — a pass verb arrived while a frame was recording: refused, change passes between frames
engine.threading.refused_from_frame   — setFrameThreading() was asked from the engine's own frame thread: the mode a frame runs under cannot end from inside it
engine.threading.refused_in_flight    — setFrameThreading() was asked from another host thread while a frame was being built: switching joins the frame thread, so ask between frames
engine.shutdown.refused_from_frame    — shutdown() was asked from the engine's own frame thread: the teardown releases what that frame is using, and a thread cannot join itself - nothing was torn down
engine.shutdown.refused_in_flight     — shutdown() was asked from another host thread while a frame was being built: the teardown releases the tables that compile walks, so ask between frames
engine.screen.no_program              — a FullscreenPass named no program, so it can never draw
engine.screen.no_input                — a FullscreenPass declared no input at all, so it samples nothing
engine.screen.no_camera               — a FullscreenPass with a fullscreen program has no camera to build its view from
engine.device.not_up                  — the device an engine borrows is not initialized: the party that created it brings it up
engine.target.unsupported_offscreen   — the backend reports no off-screen target support, so a pass staged through one lands in the window
engine.target.publish_refused         — publishing a named target was refused (the name is taken or the target is unusable)
engine.area.second_refused            — an engine already drives one render area: a second one was refused
engine.area.picture_already_declared  — one area draws one picture: the second presentation was refused
engine.area.foreign                   — the area is not the one its engine drives, so nothing it declares reaches the frame
engine.present.view_foreign           — a view bound to another engine cannot present this surface
engine.present.no_chain               — a view with no chain has nothing to present: build a chain and adopt it first
engine.present.pass_unregistered      — the pass named for presentation is not registered on this surface' engine
engine.shadow.not_built               — shadow-casting lights have no shadow pass (or fewer maps than casters): they are drawn unshadowed
engine.view.content_mismatch          — the view adopted a pipeline whose passes draw other content: its scene never reaches the surface
engine.view.content_not_bound         — the view's scene could not be bound to its chain's presenting pass because a frame kept the interval (twice, the second time after waiting): the view keeps drawing the previous scene
engine.frame.failed                   — the frame's engine half threw: the frame was not drawn, and the report names the exception

# --- engine: a backend module the registry refused (see graphics-architecture.md 2.16) ---
engine.backend.abi_missing            — the module states no graphics SDK ABI revision (built before the rule existed): rebuild it against this SDK; it was not registered
engine.backend.abi_mismatch           — the module was built against another graphics SDK ABI revision: rebuild it against this SDK; it was not registered

# --- vk backend: the session ---
vk.session.device_lost        — a device call answered VK_ERROR_DEVICE_LOST: the session is over, rebuild it
vk.session.frame_reentry      — a frame or warm-up was started from the thread already driving one: refused (FrameGate)

# --- vk backend: the window half (see vk-backend.md F3) ---
vk.window.handle_missing     — a Handle device was asked for a target and has no native window handle
vk.window.system_missing     — no window system is available, so no window surface can exist
vk.window.own_window_failed  — a Probe device's own window could not be brought up
vk.window.attach_failed      — the window's surface or swapchain could not be created (the repair is re-attaching)
vk.window.occupied           — a window this device already hands a target out for was asked for again: one window carries one live swapchain
vk.window.presenter_missing  — a window pass named no presenter this device handed out
vk.window.not_ready          — a window pass named this device's presenter, but the window has no live chain (detached, never attached, or its rebuild failed): the pass was left out
vk.window.acquire_failed     — the swapchain's next image could not be acquired
vk.window.present_unsupported     — this machine cannot present (no surface extension, or no VK_KHR_swapchain): the session runs off-screen
vk.window.surface_failed          — the host window's surface could not be created on the instance: this session presents nothing
vk.window.foreign_target          — a frame named a surface target this device did not hand out: it was refused

# --- vk backend: targets (see vk-backend.md 2.6 / 2.11) ---
vk.target.samples_above_limit             — the requested sample count is past what the device offers (limit pair)
vk.target.samples_not_a_count             — the requested sample count is not one the device offers (limit pair)
vk.target.multisampled_depth_unsupported  — a multisampled target with depth needs Vulkan 1.2's depth resolve
vk.target.borrow_multisampled             — a multisampled target cannot borrow its depth
vk.target.borrow_source_missing           — the depth lender was not built (or has no depth); it must render first
vk.target.borrow_extent_mismatch          — a borrowed depth must have the same extent as its borrower
vk.target.size_unknown                    — the target has no usable extent (0 in a dimension)
vk.target.extent_above_limit              — the declared extent is above what the device allows (limit pair)
vk.target.too_many_colors                 — the target asks for more colour attachments than the API allows
vk.target.color_format_unsupported        — the device cannot back a colour format this target asks for (drawn into, sampled and copied)
vk.target.resize_failed                   — the attachments could not be rebuilt at the new extent (see the memory report)
vk.target.build_failed                    — the attachments could not be built (see the memory report)
vk.target.claim_conflict                  — another frame driver holds this target for the frame in progress

# --- host layer (see DiagnosticOrigin): a finding the layer above injects through the engine ---
appfw.viewer.foreign_view     — a view bound to another engine cannot draw this viewer's area: it was refused
