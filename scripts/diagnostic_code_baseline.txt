# A ratchet, not an excuse:
#   * a file may not exceed the number below;
#   * a file not listed may not have any uncoded report at all, so new code names its cause;
#   * when a file drops below its ceiling, lower the number (and delete the line at 0) - the gate prints a hint.
#
# EMPTY SINCE 2026-11-16 (batch 4): the engine's own reports now name `engine.*` codes, the host's
# `appfw.viewer.*`, and both backends name `vk.*` / `vsg.*` - every report that BUILDS a diagnostic states its
# cause. A line coming back here is a report that went backwards.
#
# A report that HANDS OVER a whole diagnostic (`reportDiagnostic(diagnostic)`) is not counted at all: the value carries
# the code as a member, so the sink cannot drop it (see check_diagnostic_formats.forwards_a_diagnostic).
